# Changelog

## 0.1.0 — 2026-08-21 15:44 +08:00

Initial public Open Character Workbench release.

### Added

- installable `ocw` CLI;
- `doctor`, `new-job`, `stage`, and `validate` commands;
- SHA-256 reference manifests and evidence-isolated studios;
- vendor-neutral agent contract;
- two-view character benchmark convention;
- public/private asset policy and security guidance;
- synthetic front/side reference example;
- portable Linux Blender bootstrap;
- unit tests and GitHub Actions smoke workflow;
- publication guard for common secret and private-asset mistakes.

### Scope

This release is a reproducible workbench, not a one-click character generator. Artistic quality review remains separate from infrastructure and delivery validation.
