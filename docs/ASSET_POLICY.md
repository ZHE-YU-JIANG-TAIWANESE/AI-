# Asset and Privacy Policy

OCW's code and documentation are public. User project assets are not automatically public or relicensed.

## Safe to include

- code and documentation written for OCW;
- synthetic or self-created examples intended for redistribution;
- benchmark references with explicit redistribution permission;
- generated manifests that contain no private paths or secrets.

## Do not include without permission

- private character references;
- client art or proprietary concept sheets;
- copyrighted third-party meshes, textures, fonts, or add-ons without compatible redistribution rights;
- API keys, cookies, tokens, passwords, or environment dumps;
- personal data not needed for the benchmark.

## Repository history matters

Deleting a private asset in a later commit does not remove it from old Git history. If private material ever entered a development repository, publish a clean export in a fresh repository/history rather than changing that mixed repository to public.

## Example policy

The bundled two-view example uses simple synthetic SVG reference drawings made specifically for testing OCW. They are framework fixtures, not a real character or client asset.
